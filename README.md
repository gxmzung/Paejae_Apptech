# PAEJAE Apptech

### Early Paejae Campus App Prototype

PAEJAE Apptech is an early Flutter-based campus app experiment for exploring student-facing university service ideas.

This repository is not the final smart campus platform.  
It is kept as a public supporting repository that shows the earlier stage of campus app exploration before the ideas were narrowed into more focused projects such as `CityBrain` and `paejae-campus-os-v1`.

---

## Purpose

The project explores how a student-centered campus app could organize common university-life features into a mobile-first interface.

The focus areas include:

- campus information access
- student utility features
- mobile-first UI structure
- Flutter app architecture
- backend prototype integration
- early service flow exploration

---

## Position in Portfolio

This repository is an early-stage campus app prototype.

```text
Paejae_Apptech
→ early campus app experiment

CityBrain
→ focused smart cafeteria MVP

paejae-campus-os-v1
→ broader smart campus platform scaffold
```

This distinction is important because `Paejae_Apptech` is not intended to replace the later smart campus projects.
