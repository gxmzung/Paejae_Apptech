# 📱 PAEJAE Apptech

배재대학교 생활과 학사 정보를 더 빠르고 직관적으로 확인할 수 있도록 설계한 Flutter 기반 앱 프로젝트입니다.  
학생 관점에서 실제로 자주 쓰는 기능을 중심으로 구성하고, 캠퍼스 생활에 필요한 정보 접근성을 높이는 것을 목표로 합니다.

---

## 🚀 Project Overview

PAEJAE Apptech는 단순한 학교 앱 복제가 아니라,  
학생이 실제로 필요로 하는 기능을 더 빠르고 편하게 사용할 수 있도록 개선하는 방향으로 설계한 프로젝트입니다.

이 프로젝트에서 중점적으로 다루는 것은 다음과 같습니다.

- 학사/생활 정보 접근성 개선
- 모바일 친화적인 UI/UX 구성
- Flutter 기반 앱 구조 설계
- 실제 서비스로 확장 가능한 구조 고민

## 📂 Project Structure

```bash
lib/
├─ core/        # 공통 설정, 유틸, 상수, 테마
├─ auth/        # 인증 관련 기능
├─ features/    # 주요 기능별 모듈
├─ widgets/     # 공용 위젯
└─ main.dart    # 앱 시작점
```
